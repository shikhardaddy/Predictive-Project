6. Title of Project:
Handwritten Digit Recognition using Linear and Quadratic Discriminant Analysis (LDA vs QDA)

7. Brief About your project:
We classify 8x8 pixel images of handwritten digits (0 to 9) from the UCI Optical Recognition of Handwritten Digits dataset (1,797 images, 64 pixel features) using Linear Discriminant Analysis and compare it with Quadratic Discriminant Analysis. The covariance regularisation of both models was tuned with 5-fold cross-validation. LDA reached 95.1% test accuracy, while QDA reached 98.4% because it allows each digit its own covariance matrix. LDA was also used to project the 64 pixels onto 2 discriminant axes to visualise how well the digits separate.

8. Which machine learning approach used?
Linear Discriminant Analysis (LDA), compared with Quadratic Discriminant Analysis (QDA)
